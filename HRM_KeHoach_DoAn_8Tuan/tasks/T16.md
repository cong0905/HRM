## Việc AI phải làm
1. React TypeScript, routing, query/cache, generated API client; chọn thư viện UI nhất quán và khóa version.
2. Login/logout/quên-reset-đổi mật khẩu/session expiry, CSRF, xử lý ProblemDetails/409, loading/empty/error; không lưu cookie/token trong localStorage.
3. Navigation theo permission từ server; form validation hỗ trợ người dùng nhưng server vẫn quyết định.
